Alchemist Den es una aplicación de catálogo de cócteles que permite a los usuarios navegar y buscar varios cócteles. La aplicación obtiene datos de la API CocktailDB y los muestra de forma visualmente atractiva utilizando Tailwind CSS y Framer Motion para las animaciones.
